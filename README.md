# Αγρόκτημα

Πραγματική, λειτουργική εφαρμογή (Flask + SQLite) για αγρότες: καταγραφή
κτημάτων/εργασιών/εξόδων, χάρτης κτημάτων & δέντρων, συμβουλές AI, και
σύστημα υιοθεσίας δέντρων ελιάς με πληρωμές.

Δοκιμασμένη άκρη-σε-άκρη: εγγραφή → κτήμα → εργασία → δέντρο → υιοθεσία →
πληρωμή → επιβεβαίωση. Όλα πραγματικά, τίποτα demo/mock data.

## Τρέξιμο τοπικά (στον υπολογιστή σου)

Χρειάζεσαι Python 3.10+.

```bash
cd agroktima
pip install -r requirements.txt
python app.py
```

Άνοιξε http://localhost:5000 στον browser σου (ή στο κινητό σου, αν είναι
στο ίδιο Wi-Fi, με http://<IP-του-υπολογιστή>:5000).

Η βάση δεδομένων (agroktima.db) δημιουργείται αυτόματα την πρώτη φορά.

## Για να γίνει "ζωντανή" στο internet (ώστε να τη χρησιμοποιούν πελάτες)

Αυτή τη στιγμή τρέχει μόνο τοπικά. Για πραγματική χρήση χρειάζεσαι hosting.
Πιο απλές επιλογές για αρχή (όλες έχουν δωρεάν πλάνο):

1. **Render.com** — συνδέεις το GitHub repo σου, επιλέγεις "Web Service",
   βάζεις `pip install -r requirements.txt` ως build command και
   `python app.py` ως start command. ~10 λεπτά.
2. **Railway.app** — παρόμοιο με το Render, πολύ απλό για Flask apps.
3. **PythonAnywhere** — ειδικά φτιαγμένο για Python/Flask, καλό για αρχή.

Μόλις ανέβει, θα έχεις μια πραγματική διεύθυνση (π.χ.
`agroktima.onrender.com`) που δουλεύει από οποιοδήποτε κινητό/υπολογιστή,
χωρίς εγκατάσταση — ήδη λειτουργεί σαν web app.

**Σημαντικό πριν ανεβεί "ζωντανά":** άλλαξε το `SECRET_KEY` στο `app.py`
(ή βάλε το ως μεταβλητή περιβάλλοντος `SECRET_KEY`) σε κάτι τυχαίο και
μυστικό — αυτό τώρα είναι `dev-secret-change-me`, μόνο για δοκιμή.

## Για να ενεργοποιηθούν πραγματικές πληρωμές (Stripe)

Αυτή τη στιγμή οι πληρωμές είναι σε "δοκιμαστική λειτουργία" (test mode) —
η ροή δουλεύει κανονικά αλλά δεν χρεώνεται καμία κάρτα. Για πραγματικές:

1. Φτιάξε λογαριασμό στο https://stripe.com (χρειάζεται ΑΦΜ/τραπεζικό λογαριασμό)
2. `pip install stripe`
3. Όρισε τις μεταβλητές περιβάλλοντος:
   ```bash
   export STRIPE_SECRET_KEY="sk_live_..."
   export STRIPE_PUBLISHABLE_KEY="pk_live_..."
   ```
4. Η εφαρμογή ανιχνεύει αυτόματα το κλειδί και περνάει σε πραγματικές
   πληρωμές μέσω Stripe Checkout — δεν χρειάζεται καμία αλλαγή στον κώδικα.

## Καταγραφή παραγωγής

Σε κάθε κτήμα ο αγρότης καταχωρεί τη συγκομιδή του (ημερομηνία, είδος —
ελιές/ελαιόλαδο/άλλο — και ποσότητα σε κιλά, με προαιρετικές σημειώσεις).
Η σελίδα του κτήματος δείχνει το σύνολο ανά είδος και πλήρες ιστορικό, και
η σελίδα "Παραγωγή & Έξοδα" δείχνει το άθροισμα σε όλα τα κτήματα μαζί. Τα
στοιχεία παραγωγής μπαίνουν αυτόματα και στο context των συμβουλών AI.

## Χάρτης κτημάτων & δέντρων

Δουλεύει ήδη πλήρως, χωρίς κανένα κλειδί API — χρησιμοποιεί OpenStreetMap
(δωρεάν, χωρίς όριο χρήσης για μικρή κλίμακα). Ο αγρότης μπορεί:
- Να σημαδέψει το κτήμα του κάνοντας κλικ στον χάρτη, να πληκτρολογήσει
  συντεταγμένες απευθείας, ή να χρησιμοποιήσει το κουμπί "τρέχουσα θέση μου"
- Να δει όλα τα κτήματά του μαζί σε έναν συνολικό χάρτη (`/fields/map`)
- Να σημαδέψει το ακριβές σημείο κάθε δέντρου ξεχωριστά (αν δεν σημαδευτεί,
  εμφανίζεται στη θέση του κτήματος)

Ο πελάτης βλέπει το σημείο του δέντρου του στη σελίδα του δέντρου και στις
"Υιοθεσίες μου".

## Συμβουλές AI

Ο αγρότης ρωτάει οτιδήποτε (π.χ. "πότε να λιπάνω;") στη σελίδα "Συμβουλές
AI" και παίρνει απάντηση βασισμένη στα δικά του καταγεγραμμένα δεδομένα
(κτήματα, εργασίες, ιστορικό). Λειτουργεί ήδη χωρίς κανένα κλειδί — δίνει
βασικές, κανόνα-βασισμένες συμβουλές από το ιστορικό σου (π.χ. "το τελευταίο
πότισμα στο Χ ήταν πριν 12 μέρες").

**Για πλήρεις απαντήσεις AI (ελεύθερου κειμένου, πιο έξυπνες):**
1. `pip install anthropic`
2. Φτιάξε κλειδί API στο https://console.anthropic.com
3. `export ANTHROPIC_API_KEY="sk-ant-..."`
4. Η εφαρμογή ανιχνεύει αυτόματα το κλειδί και περνάει σε πραγματικές
   απαντήσεις AI — καμία αλλαγή κώδικα.

## Για να γίνει εφαρμογή σε App Store / Google Play

Μόλις η εφαρμογή είναι "ζωντανή" σε μια πραγματική διεύθυνση (βήμα
παραπάνω), το πιο γρήγορο μονοπάτι για τα καταστήματα είναι να τη
"τυλίξεις" με ένα εργαλείο όπως το **Capacitor** ή το **PWABuilder**, που
παίρνει μια web εφαρμογή και βγάζει πραγματικό .ipa/.apk γύρω της — δεν
χρειάζεται να ξαναγραφτεί ο κώδικας. Χρειάζεσαι:
- Λογαριασμό Apple Developer (~99$/έτος) για το App Store
- Λογαριασμό Google Play Console (~25$ εφάπαξ) για το Google Play

Πες μου όταν φτάσεις σε αυτό το σημείο και σε καθοδηγώ βήμα-βήμα.

## Δομή κώδικα

```
app.py          — κεντρική εφαρμογή, σύνδεση όλων των κομματιών
db.py           — σύνδεση SQLite
schema.sql      — δομή βάσης δεδομένων
auth.py         — εγγραφή/σύνδεση, ρόλοι (αγρότης/πελάτης)
fields.py       — κτήματα, καταγραφή εργασιών, θέση στον χάρτη
stats.py        — σύνοψη εξόδων/εσόδων
trees.py        — δέντρα προς υιοθεσία, θέση στον χάρτη, ροή πληρωμής
payments.py     — ενσωμάτωση Stripe (με αυτόματο test-mode fallback)
advisor.py      — συμβουλές AI (σελίδα ερωτήσεων + ιστορικό)
advisor_ai.py   — λογική AI advisor (με αυτόματο fallback χωρίς κλειδί)
uploads.py      — ασφαλής αποθήκευση φωτογραφιών
templates/      — HTML σελίδες
templates/_map_macros.html — επαναχρησιμοποιήσιμος κώδικας χάρτη (Leaflet)
static/style.css — όλο το design
```

## Τι λείπει ακόμα (επόμενα βήματα)

- Πραγματικές πληρωμές Stripe (σκόπιμα αφήνεται για το τέλος)
- Πραγματικό μοντέλο AI στις συμβουλές (χρειάζεται κλειδί ANTHROPIC_API_KEY)
- App Store / Google Play (η εφαρμογή είναι μόνο web αυτή τη στιγμή)
- Email ειδοποιήσεις (π.χ. όταν γίνει νέα υιοθεσία)
- Αυτόματες αναφορές ΟΠΕΚΕΠΕ/ΕΛΓΑ (το συζητήσαμε ως ιδέα διαφοροποίησης)
- Προστασία από spam/bot στην εγγραφή (π.χ. rate limiting)
